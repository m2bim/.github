## Overview

**m2BIM** is a structural BIM practice dedicated to advancing the field through **high-quality information management**, **automation**, and adherence to **international BIM standards**.

This GitHub organization hosts **m2LAB** — an open research space for developing and sharing practical BIM tools and workflows that are actively used in real-world projects.

## Focus Areas

### 🏗️ Structural BIM Automation
Developing tools and workflows to automate repetitive tasks and improve efficiency in structural BIM processes.

### 📋 ISO 19650–Aligned Information Management
Implementing and promoting best practices aligned with ISO 19650 standards for information management in construction projects.

### 🛠️ Development Platforms
- **Revit API** — Custom tools and extensions for Autodesk Revit
- **Dynamo** — Visual programming for BIM automation
- **pyRevit** — Python-based Revit scripting framework
- **Rhino** — Advanced 3D modeling and computational design

### 🌐 Open but Practice-Driven Tooling
Creating open-source tools that are grounded in real-world project experience and practical needs.

**Core Technologies:**
- **Revit API** — Autodesk Revit application programming interface
- **Dynamo** — Visual programming environment for BIM
- **Python** — Primary scripting language
- **pyRevit** — Python-based Revit add-in framework
- **Rhino** — 3D modeling and computational design software
- **Web Services** — RESTful APIs and web integrations
- **IFC** — Industry Foundation Classes for open BIM data exchange
